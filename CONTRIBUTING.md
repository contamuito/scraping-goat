# Contributing to Scraping G.O.A.T.

Thank you for considering a contribution to **Scraping G.O.A.T.**!

### Guidelines

1. **Relevance:** Only suggest tools that are genuinely effective against modern scraping challenges (TLS fingerprinting, browser anti-detection, fast parsing, or anti-bot bypass).
2. **Maintenance:** Ensure the suggested tool or repository is active, working, or historically foundational.
3. **Format:** Keep the format consistent: `[Tool Name](URL) (Language) - Concise description of what it does and why it matters.`
4. **No Marketing Spam:** Commercial tools must have a significant open-source component, SDK, or self-hostable core to be listed.

### How to Submit

1. Fork this repo.
2. Create a branch: `git checkout -b add-tool-name`.
3. Add your change to `README.md`.
4. Commit your changes: `git commit -m "add <tool-name> to <category>"`.
5. Push to your fork and submit a Pull Request.
